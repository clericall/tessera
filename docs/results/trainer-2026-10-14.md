# Trainer improvements — honest validation, schedules, game-wise batching

**Date:** 2026-10-14 · **Files:** `tools/train.py`, `tools/sweep.py`

## 1. Validation split by game (the important one)

`gen_data.py` now stamps a game id into the previously reserved byte 35 of each record, and
`train.py` splits train/validation **by game** rather than by position.

Positions inside one game share an opening and a set of tactics, so a random position split leaks:
the model sees near-identical positions on both sides and the reported correlation flatters it. The
numbers show exactly how much:

| dataset | split | correlation |
|---|---|---|
| 4k positions (40 games) | by position | +0.890 |
| 37k positions (400 games) | by position | +0.600 |
| 142k positions (1500 games) | **by game** | **+0.502** |

The honest number is the last one. The earlier figures are kept above only to document the size of
the leak — they are not comparable to it.

## 2. Game-wise batching

Within an epoch, games are shuffled and each game's positions are shuffled and kept contiguous
before batching. Correlated positions no longer land in unrelated minibatches, which makes the
gradient estimate less noisy at the same step count.

## 3. Cosine schedule with warmup

`--schedule cosine` (now the default) warms up over `--warmup-epochs` then decays to zero; the
previous flat `--lr` remains available via `--schedule constant`.

## 4. Calibration is unchanged, still necessary

The output scale is fitted on the validation split (`score = value * scale / 64`, so scaling the
net's output is just a scale-field change). The last run needed a factor of 0.87-0.88; without it
the net emits centipawn values several times too large, which makes the engine play on noise.

## 5. `--drop-draws` experiment flag

Self-play between clones produces ~45% draws. `--drop-draws` trains only on decisive positions so
the dilution can be measured rather than argued about.

## 6. `tools/sweep.py`

Runs several configurations on the same split and prints one table (hidden width, schedule, draw
filtering, validation MSE, validation correlation, resulting net path), then names the best by
correlation. Hyper-parameters are now *measured*, not picked by intuition:

```
    python tools/sweep.py --data selfplay.bin --outdir sweep --configs quick
```

## Verification

- `gen_data.py --selftest` and `train.py --selftest` both pass after the record-format change.
- Engine and trainer still agree on the score; the parity check in
  `tools/run_nnue_pipeline.ps1` re-runs it every cycle.
- Perft unchanged on all six reference positions; the legacy `engine/e1.ter` (mailbox) and
  `engine/uci.ter` still build and return the moves recorded in their milestone docs.

## Unrelated finding

`samples/ok.ter` does not compile — it uses `type BitBoard = u64;` aliases and `#[default]`
attribute arguments, neither of which the checker implements. That is pre-existing (the sample
documents the intended language surface, not the implemented one) and is unrelated to anything in
this milestone.
